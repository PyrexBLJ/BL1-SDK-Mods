# BL1 Python SDK Mods
my mods for the borderlands 1 python sdk
feel free to use/edit em

# List of mods

![Bonk Utilities](https://github.com/PyrexBLJ/BL1-SDK-Mods/tree/main/BonkUtilities)
The returning absolute mess of a utility mod. theres a bunch of stuff in here and no i probably wont clean up the source.

![Farm Tracker](https://github.com/PyrexBLJ/BL1-SDK-Mods/tree/main/FarmTracker)
Mod that is able to track various in game things, then print them to text files for use in obs/other screen capture software.

![Part Display](https://github.com/PyrexBLJ/BL1-SDK-Mods/tree/main/PartDisplay)
Shows weapon and item parts on screen when looking at a dropped item.

![Aim Speed](https://github.com/PyrexBLJ/BL1-SDK-Mods/tree/main/AimSpeed)
Configurable separate mouse/controller look sensitivity when aiming down sights with a sniper.

![4 Player Difficulty](https://github.com/PyrexBLJ/BL1-SDK-Mods/tree/main/4PlayerDifficulty)
Default the game to always set the difficulty as if there were 4 players in the lobby.

![Plywood Detector](https://github.com/PyrexBLJ/BL1-SDK-Mods/tree/main/PlywoodDetector)
Pop up a notification on screen and play a sound whenever a gun with plywood in the name spawns.

![Jumpscares](https://github.com/PyrexBLJ/BL1-SDK-Mods/tree/main/Jumpscares)
1/10000 chance of a jumpscare popping up every second. plays a random one by default.
